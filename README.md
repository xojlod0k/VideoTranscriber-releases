# Video Transcriber — загрузки и обновления

Здесь выходят готовые версии программы Video Transcriber — офлайн-транскрибации видео в TXT с таймкодами
(Whisper large-v3 на видеокарте NVIDIA, Windows 10/11).

Скачайте архив по ссылке ниже, распакуйте и запустите `VideoTranscriber.exe`. Инструкция — «Прочитай меня.txt» в архиве.
Все версии лежат в папке [releases](releases).

Программа (начиная с 1.1.0) сама проверяет этот репозиторий при запуске и, когда выходит новая версия, показывает
«Доступна новая версия — обновитесь»; проверить вручную — «Настройки → Проверить обновления…».

<!-- latest:start -->
**Последняя версия — 1.2.0:** [скачать VideoTranscriber-1.2.0.zip](https://github.com/xojlod0k/VideoTranscriber-releases/raw/main/releases/VideoTranscriber-1.2.0.zip)

Что нового:

- Скачивание видео по ссылке: YouTube, TikTok, Instagram, VK, Rutube и сотни других сайтов — кнопка «По ссылке» (Ctrl+L), или просто вставьте ссылку в окно (Ctrl+V) или перетащите её из браузера.
- У скачанного видео — кнопка «Транскрибировать»: ставит его в очередь и сразу запускает. Галочка «Сразу транскрибировать после скачивания» делает это сама.
- Можно вставить несколько ссылок сразу — скачаются по очереди, с прогрессом.
- Видео сохраняются в «Видео\Video Transcriber», папку можно сменить.
- Загрузчик видео (yt-dlp, около 20 МБ) скачается сам при первом использовании и будет сам обновляться.
