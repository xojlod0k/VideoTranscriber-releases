# Video Transcriber — загрузки и обновления

Здесь выходят готовые версии программы Video Transcriber — офлайн-транскрибации видео в TXT с таймкодами
(Whisper large-v3 на видеокарте NVIDIA, Windows 10/11).

**Скачать:** [последняя версия](https://github.com/xojlod0k/VideoTranscriber-releases/releases/latest) → файл `VideoTranscriber-<версия>.zip`,
распакуйте и запустите `VideoTranscriber.exe`. Инструкция — «Прочитай меня.txt» в архиве.

Программа (начиная с 1.1.0) сама проверяет эту страницу при запуске и, когда выходит новая версия, показывает
«Доступна новая версия — обновитесь»; проверить вручную — «Настройки → Проверить обновления…».
