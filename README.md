# Video Transcriber — загрузки и обновления

Здесь выходят готовые версии программы Video Transcriber — офлайн-транскрибации видео в TXT с таймкодами
(Whisper large-v3 на видеокарте NVIDIA, Windows 10/11).

Скачайте архив по ссылке ниже, распакуйте и запустите `VideoTranscriber.exe`. Инструкция — «Прочитай меня.txt» в архиве.
Все версии лежат в папке [releases](releases).

Программа (начиная с 1.1.0) сама проверяет этот репозиторий при запуске и, когда выходит новая версия, показывает
«Доступна новая версия — обновитесь»; проверить вручную — «Настройки → Проверить обновления…».

**Последняя версия — 1.1.1:** [скачать VideoTranscriber-1.1.1.zip](https://github.com/xojlod0k/VideoTranscriber-releases/raw/main/releases/VideoTranscriber-1.1.1.zip)

Что нового:

- Программа сама сообщает о новой версии: «Доступна новая версия — обновитесь», обновление в один клик.
- Настройки → «Проверить обновления…» и «Проверять обновления при запуске».
- В «О программе» видна версия.
- Проверка обновлений не зависает на медленной сети.
- Если у вас версия 1.0 — скачайте этот архив вручную один раз, дальше обновления придут сами.
